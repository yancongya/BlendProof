# Phase 2 Plan 01: Anchored Review Comments

## Goal

在阶段 1 的同一 Viewer 中加入表面锚定评论、稳定视角重放和只读分享重放，不建立第二套查看器。

## Wave 1: Contract and repository boundary

1. 固定 `ReviewComment` 与 `ReviewCameraState` 数据合同。
2. 提供项目评论的读取、创建、更新 API；首轮可持久化到项目目录 JSON。
3. 客户端通过 repository 层调用，避免阶段 3 迁移 SQLite 时修改 Viewer。

## Wave 2: Placement and presentation

1. 添加显式“添加批注”模式。
2. 射线命中模型表面，保存世界坐标、世界法线、对象名和活动相机状态。
3. Billboard pin 与右侧评论面板共享选中状态。

## Wave 3: Replay and sharing

1. 点击评论恢复相机投影、姿态与导航 target。
2. 项目页可创建、编辑、解决评论。
3. 分享页复用同一组件，只读加载评论和视角。

## Verification

1. 静态检查与生产构建。
2. 项目页创建评论、刷新后仍存在。
3. 相机重放前后截图并等待 900 ms，确认无闪回。
4. 第二个隔离浏览器会话打开分享链接，正文和 pin 一致且无编辑入口。
5. 页面控制台和评论 API 无错误。

状态：已于 2026-09-09 完成。证据见 `02-01-SUMMARY.md`。

## Out of Scope

- 完整账户系统、访客身份、密码、有效期和权限矩阵。
- SQLite/D1/R2；这些属于阶段 3/4，但 API 和 repository 必须为迁移保留边界。
