# Phase 0 Plan 01: Research Baseline

## Goal

建立可重复的 Viewer 验收基线，先证明测试数据与问题边界，再进入 Viewer 内核替换。

## Tasks

1. 固定参考仓库清单，并记录每个项目对 BlendProof 的参考职责。
2. 生成三组可重复测试资产：无相机、单相机、多相机；相机视角必须与默认透视明显不同。
3. 形成 Viewer 交互验收矩阵，覆盖相机、投影、选择、框选、局部视图、显示模式和 Blender 式导航。
4. 在本地 Web 中载入测试资产，记录浏览器验收结果与已知失败。
5. 更新长期计划状态并生成阶段摘要与项目状态。

## Execution Waves

- Wave 1：参考清单、验收矩阵、测试场景生成器。
- Wave 2：生成资产并验证 GLB 内容。
- Wave 3：浏览器验收、阶段结论与状态更新。

## Completion Criteria

- 三类 `.blend`、`.glb`、manifest 都能通过一条命令重新生成。
- manifest 能准确区分 0、1、2 个文件相机。
- 当前 Viewer 的通过项和失败项有真实运行证据。
- 阶段 1 的技术决策输入完整，不再依赖口头上下文。
