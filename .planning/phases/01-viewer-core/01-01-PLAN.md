# Phase 1 Plan 01: Viewer Core

## Goal

基于已克隆的 Viewer 参考项目，修复 GLB 呈现和文件相机切换，不再把文件相机当作普通场景节点变换。

## Decisions

- 保持 Three.js/R3F 作为产品渲染适配层；不复制 Online3DViewer 的整套网站与多格式导入器。
- 采用 Online3DViewer 的核心边界：导入场景保持原始世界变换，导航相机独立于导入模型。
- 以 glTF-Sample-Viewer 的相机枚举原则保留每一个导入相机及其投影类型。

## Completed

1. API、分享页、模型 URL 改为同源相对路径，开发服务器代理 `/api` 和 `/files`。
2. 移除了会重定位导入相机的 `Bounds` 与 `Center` 包装，初始化导航相机朝向场景原点。
3. 文件相机切换时克隆源相机、复制世界变换并保留透视/正交投影类型。
