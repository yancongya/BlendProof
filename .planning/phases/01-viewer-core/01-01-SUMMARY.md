# Phase 1 Plan 01 Summary: Viewer Core

## Outcome

阶段 1 已通过真实浏览器验收。导入相机保持世界变换和透视/正交投影，导航相机按模型边界取景，文件相机切换不会被默认相机复位。

## Implemented

- 同源加载 API 与模型文件，上传页和分享页继续复用同一个 Viewer。
- 文件相机枚举、克隆、世界变换及投影切换。
- 1、3、7、0 预设视图与模型边界自动取景。
- 点击选择、空白清除、基于物体屏幕包围盒的框选和 `/` 局部视图。
- 中键旋转、Shift+中键平移、滚轮缩放，以及线框、灰模、材质显示模式。

## Verification

- `npm run check`
- `npm run build`
- Playwright 分别打开无相机、单相机、多相机分享链接。
- 文件相机切换后立即与 900 ms 后截图哈希一致。
- 选择、框选、独显、显示模式和三种导航操作均取得浏览器画布证据。
- 最终控制台 0 error、0 warning。

## Next

进入阶段 2，先从 Share 与 Open3DInspection 的参考实现提取评论锚点和相机状态数据合同，再在同一 Viewer 中实现创建与只读重放。
