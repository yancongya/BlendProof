## 二、双身份塔罗牌（Tarot Cards）3D 视差设计与交互规范

### 1. 设计概念与阿卡那原型
- **卡牌 1：【I · 造物者 / The Artificer】（3D 创作者）**
  - **核心象征**：悬浮猴头 Suzanne、3D 空间坐标环、源工程不出机的安全印戒。
  - **色彩基调**：Blender 暖橙金（`#e87d0d` / `#f59e0b`）+ 玄武岩哑光灰（`#1c1c1f`）。
  - **文案**：“工程在手，安全闭环 · 零摩擦转换与分享”。
- **卡牌 2：【II · 审视者 / The Seer】（客户 / 审稿人 / 总监）**
  - **核心象征**：空间全视之眼、精准坐标光之图钉、免装客户端的透明浏览器光幕。
  - **色彩基调**：科技冷翠青与青金石蓝（`#38bdf8` / `#22c55e`）+ 银冷金滚边（`#94a3b8`）。
  - **文案**：“免装软件，浏览器秒开 · 3D 空间指哪点哪”。

### 2. 分层架构（Hybrid Layering）
每张卡牌具备 4 层深度，通过 CSS `transform-style: preserve-3d` 与动态视差计算实现：
- Layer 0 (Z: 0px): 底板质感层（深色星轨、几何暗纹）
- Layer 1 (Z: 24px): 卡心艺术插画（高精生成的专属塔罗牌面）
- Layer 2 (Z: 48px): 矢量烫金外边框（SVG 精密雕花、罗马数字、星座角标、文字）
- Layer 3 (Z: 64px): 动态全息反光膜（Holographic Glare，CSS 渐变跟随鼠标光照角度流动）

### 3. 视差动力学与光影交互算法
- 鼠标监听：卡牌内部监听 `pointermove`，计算相对于卡片中心的归一化坐标 (dx, dy) ∈ [-1, 1]。
- 倾角映射：RotateY = dx × 14deg, RotateX = -dy × 14deg。
- 反光光斑映射：高光中心跟随鼠标坐标，伴随虹彩衍射光泽。
- 离开卡片：`pointerleave` 时平滑缓动复位至原点。
