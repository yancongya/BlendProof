06公益性质Public Pool · 5 GiB

一个不打算收费的存储池。

BlendProof 更像一个审稿件的临时快递柜：包裹到期自动清空，全程无人开箱。个人维护的公益项目，不做付费档位。

  • 免费使用。注册与审稿都不收费，也没有付费解锁的功能。
  • 5 GiB 共享容量。所有用户共用一个总量上限，用完即止，不超额透支。
  • 到期自动清理。项目最长保留 48 小时，分享默认 24 小时，每小时定时任务按精确 key 删除。
  • 上限优先于便利。容量与保留期被硬约束保护，管理员只能在 5 GiB / 48 小时内调低，不能调高。
  • 邀请码注册。不开放自由注册，是为了让容量和清理节奏可控——这是公益池能长期跑下去的前提。
  • 不看你的内容。服务端只转发派生资产，没有人工查看环节；日志只记操作，不看模型。
  • 开源，可自行部署。不放心公益池？代码全部公开，可以自己搭一套一模一样的。

08技术栈与支持范围Under the Hood

它是怎么工作的，以及能覆盖多少。

没有魔法——浏览器标准能力 + Blender 官方能力 + 一层薄服务端。免安装路径覆盖静态场景，复杂文件自动回退本机 Blender。

前端React 19 · three.js / R3F · Vite
转换浏览器解析优先 · 复杂回退本机 Blender
服务端Cloudflare Workers · D1 · R2 · 每小时 cron 清理
本地桥接Node 22 · Express · 仅监听 loopback
  1. 浏览器优先转换。页面内直接解析受支持的 .blend；不支持的文件回退到你本机的 Blender 导出 GLB 与清单。原件不参与任何网络传输。
  2. 受控上传。只有派生资产被推到云端，415 硬门槛挡住一切工程原件。
  3. 凭证分享。一条带权限与有效期的链接，对方浏览器直接渲染，无需安装。
  4. 到期清空。每小时定时任务按精确 key 删除过期资产，不做长期留存。

转换为 GLB：留下什么，丢掉什么

转换后能看到
  • 修改器求值后的网格与拓扑
  • 对象层级、名称与集合结构
  • PBR 材质基础属性（基础色 / 粗糙度 / 金属度 / 贴图）
  • 场景相机与灯光
  • 动画与骨骼绑定（经本机 Blender 导出时）
GLB 带不走
  • 物理、粒子、流体、布料等模拟
  • 程序化节点的可调参数——几何节点只留烘焙结果
  • 合成器 / 世界节点与后期效果
  • Blender 专有着色，以及 Cycles / Eevee 的像素级观感
  • 插件数据、链接库与工程内部结构

两条转换路径，能力不同。浏览器直转只覆盖静态网格子集，材质按首材质近似；需要动画、骨骼或完整着色时会自动回退到你本机的 Blender 导出。无论哪条路径，审稿者看到的都是转换后的展示模型，不是 Blender 里的实时画面。

隐私政策

数据处理范围

原始 .blend 文件仅在浏览器页面内或您本机的 Blender bridge 中读取和转换，不会上传至 BlendProof 云端。您确认发布后，云端仅保存用于审阅的轻量 GLB、裁剪后的 manifest、可选缩略图、分享设置和批注。

账号与日志

邀请码注册会处理邮箱、显示名称、账号角色、会话与邀请码使用记录。为保障安全、容量控制和故障排查，服务会保留必要的访问、发布、分享和清理日志。

保留与删除
