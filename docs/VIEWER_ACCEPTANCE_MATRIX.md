# Viewer 验收矩阵

## 测试资产

| 资产 | 相机数量 | 用途 |
| --- | ---: | --- |
| `viewer-no-camera` | 0 | 默认相机和适配窗口 |
| `viewer-single-camera` | 1 | 文件相机读取及稳定切换 |
| `viewer-multi-camera` | 2 | 相机枚举、命名和连续切换 |

## 必须通过的交互

| 能力 | 操作 | 期望结果 | 当前状态 |
| --- | --- | --- | --- |
| 默认视图 | 打开无相机模型 | 自动适配模型且无遮挡 | 待验收 |
| 文件相机 | 点击文件相机 | 保持该相机位置、朝向和投影，不闪回 | 已知失败 |
| 多相机 | 连续点击两个文件相机 | 每次准确切换且按钮状态一致 | 待验收 |
| 正交视图 | 1、3、7 | 正、右、顶视图稳定切换 | 待验收 |
| 透视视图 | 0 | 回到透视视图 | 待验收 |
| 点击选择 | 点击物体 | 仅目标物体高光 | 待验收 |
| 清空选择 | 点击空白 | 所有高光消失 | 待验收 |
| 框选 | 左键拖拽 | 选框内对象同时选中 | 待验收 |
| 局部视图 | 选择后按 `/` | 仅显示选中对象，再按恢复 | 待验收 |
| 显示模式 | 切换线框、灰模、材质 | 模式稳定且选择状态不丢失 | 待验收 |
| Blender 导航 | 中键、Shift+中键、滚轮 | 旋转、平移、缩放符合 Blender 习惯 | 待验收 |

## 证据要求

- 静态检查和构建只能证明代码可编译，不能标记交互通过。
- 相机切换必须使用视角明显不同的测试相机进行截图或自动化验证。
- 每个失败项必须记录复现资产、操作和实际结果。
