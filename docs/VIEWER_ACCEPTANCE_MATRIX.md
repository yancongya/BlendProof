# Viewer 验收矩阵

## 测试资产

| 资产 | 相机数量 | 用途 |
| --- | ---: | --- |
| `viewer-no-camera` | 0 | 默认相机和适配窗口 |
| `viewer-single-camera` | 1 | 文件相机读取及稳定切换 |
| `viewer-multi-camera` | 2 | 相机枚举、命名和连续切换 |

## 必须通过的交互

| 能力 | 操作 | 期望结果 | 当前状态 |
| --- | --- | --- | --- |
| 默认视图 | 打开无相机模型 | 自动适配模型且无遮挡 | 通过 |
| 文件相机 | 点击文件相机 | 保持该相机位置、朝向和投影，不闪回 | 通过 |
| 多相机 | 连续点击两个文件相机 | 每次准确切换且按钮状态一致 | 通过 |
| 正交视图 | 1、3、7 | 正、右、顶视图稳定切换 | 通过 |
| 透视视图 | 0 | 回到透视视图 | 通过 |
| 点击选择 | 点击物体 | 仅目标物体高光 | 通过 |
| 清空选择 | 点击空白 | 所有高光消失 | 通过 |
| 框选 | 左键拖拽 | 选框内对象同时选中 | 通过 |
| 局部视图 | 选择后按 `/` | 仅显示选中对象，再按恢复 | 通过 |
| 显示模式 | 切换线框、灰模、材质 | 模式稳定且选择状态不丢失 | 通过 |
| Blender 导航 | 中键、Shift+中键、滚轮 | 旋转、平移、缩放符合 Blender 习惯 | 通过 |

## 证据要求

- 静态检查和构建只能证明代码可编译，不能标记交互通过。
- 相机切换必须使用视角明显不同的测试相机进行截图或自动化验证。
- 每个失败项必须记录复现资产、操作和实际结果。

## 2026-09-08 浏览器证据

- `viewer-no-camera`：确认无文件相机按钮，导航相机按场景边界自动取景。
- `viewer-single-camera`：枚举出“正面审稿相机”，点击后按钮保持激活。
- `viewer-multi-camera`：低角度透视与顶部正交两次切换后分别等待 900 ms，前后截图哈希一致，没有闪回。
- 1、3、7、0 四个预设视图截图哈希各不相同，按钮状态与当前视图一致。
- 画布点击选择“可替换部件”；空白点击后选中数归零；拖框同时选中 3 个对象；`/` 状态栏进入与退出“局部视图”。
- 线框、灰模、材质按钮均进入激活态；中键旋转、Shift+中键平移、滚轮缩放产生互不相同且稳定的画布结果。
- 最终页面控制台为 0 error、0 warning；构建仅保留包体积提示。
